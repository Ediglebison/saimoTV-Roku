Bitmap artwork for the Roku interface. The manifest points to the channel icons and splash screens, while `MainScene.xml` and the navigation code point to the backgrounds, logo, focus states, and navigation icons.

## Constraints

- MUST keep the icon and splash filenames used by `manifest`.
- MUST keep the image paths referenced by `MainScene.xml` and `MainScene.brs` valid.

## Guidance

- SHOULD regenerate the artwork with `python3 tools/make_artwork.py` or `npm run art` to keep the visual system consistent.
