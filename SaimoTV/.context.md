The Roku application package. It contains the manifest, SceneGraph components, shared BrightScript functions, bitmap assets, and bundled Roboto fonts that form the sideloadable channel.

## Summary

- `components/` — Scene layout, background tasks, navigation, screens, views, and player controller.
- `fonts/` — Bundled Roboto faces and license.
- `images/` — Icons, splash screens, backgrounds, navigation art, and focus bitmaps.
- `source/` — Application entry point and shared pure BrightScript helpers, including `bslib.brs`, `theme.brs`, and `utils/Storage.brs`.
- `manifest` — Roku channel identity, version 2.6.0, splash images, and FHD resolution.
- `components/screens/FichaScreen.brs` — cinematic movie and series detail with real episodes, seasons, watched state, and resume.
- `components/screens/SettingsScreen.brs` — settings for playlist URL, VOD URL, user agent, audio prefs, cache, and About.
- `components/items/EpisodeItem.brs` — episode card with poster, number, and watched badge.
- `components/tasks/StreamResolverTask.brs` — stream candidate resolution with hoisted `SaimoTV/2.6.0 (RokuOS)` user agent.
- `components/tasks/ConnectTask.brs` — active Saimo Connect server: port 8999, same-LAN control, discovery `/info`, WebSocket commands, no new screens.
- `components/tasks/AcervoTask.brs` — network-only VOD catalog task (`roku/indice.txt` index and 50-item pages); `source/utils/Storage.brs` gains the `LoadPreferences()` alias over the existing `vodUrl`/`playlistUrl` keys.

## Constraints

- MUST keep the version in `manifest`, `package.json`, `package-lock.json`, and StreamResolverTask in sync at 2.6.0; `tools/check_project.py` enforces the match.
- MUST keep `ui_resolutions=fhd` in `manifest`; the layout and artwork target 1920x1080.
- MUST keep component scripts paired with same-named XML definitions under `components/`.
- `epgUrl` remains a legacy registry key for compatibility only; it is not a Settings UI item.
- MUST use `ReadSaimoKey`/`WriteSaimoKey` for registry values.

## Guidance

- SHOULD build through `npm run build`, which stages this directory into `.roku-build`.
- SHOULD run `npm run check`, `npm test`, `npm run build`, and `npm run package` after source changes.
