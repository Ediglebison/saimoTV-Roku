The Roku application package. It contains the manifest, SceneGraph components, shared BrightScript functions, bitmap assets, and bundled Roboto fonts that form the sideloadable channel.

## Summary

- `components/` — Scene layout, background tasks, navigation, settings, and player controller.
- `fonts/` — Bundled Roboto faces (Regular, Medium, Bold, Black, Italic) and their Apache 2.0 license file.
- `images/` — Icons, splash screens, backgrounds, navigation art, and focus bitmaps.
- `source/` — Application entry point and shared pure BrightScript helpers.
- `manifest` — Roku channel identity, version 2.5.12, splash images, and FHD resolution.

## Constraints

- MUST keep the version in `manifest` at 2.5.12 until the package files change together; `tools/check_project.py` enforces the match.
- MUST keep `ui_resolutions=fhd` in `manifest`; the layout and artwork target 1920x1080.
- MUST keep component scripts paired with same-named XML definitions under `components/`.

## Guidance

- SHOULD build through `npm run build`, which stages this directory into `.roku-build`.
