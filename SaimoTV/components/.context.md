<context path="SaimoTV/components" updated="2026-10-22">

SceneGraph components that render the interface and run network work. `MainScene` owns navigation and playback, `FetchTask` handles playlist and catalog downloads, and `EpgTask` parses XMLTV.

## Summary

- `EpgTask.brs` — Task that downloads XMLTV and keeps the current and next programme for each channel.
- `EpgTask.xml` — Defines the `EpgTask` fields and script imports.
- `FetchTask.brs` — Dispatches playlist, Saimo index, letter, episode, artwork, search, and M3U VOD downloads.
- `FetchTask.xml` — Defines the `FetchTask` fields and script imports.
- `MainScene.brs` — Controls views, navigation, settings, favorites, sync, cache, EPG, and the video player.
- `MainScene.xml` — Defines the main scene, lists, poster grid, settings, guide, about, player, and timers.

## Constraints

- MUST keep each `.brs` file paired with an XML component of the same name.
- MUST run network downloads and large catalog parsing in Task components; `MainScene.brs` must not read `fichas.txt`.
- MUST keep every `m.top.findNode` identifier present in `MainScene.xml`; `tools/check_project.py` verifies this.

## Guidance

- SHOULD keep scene state changes in `MainScene.brs` and reusable parsing logic in `source/bslib.brs`.
