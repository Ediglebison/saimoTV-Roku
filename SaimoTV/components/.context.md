SceneGraph components for the full-architecture migration: thin router shell, screens, views, items, and tasks. Items retained from the monolith are gone; adopted ref components replace them.

## Summary

- `MainScene.xml|.brs` — Thin router shell (ref MainScene base): 8-tab `TopNavBar`, `switchScreen`/`goBack`, focus handoff, cache holders, `startConnect`, and the single `montarArvore` supplier that rebuilds `ArvoreCanaisTask` when channels or EPG change; no inline view markup.
- `views/TopNavBar.*` — Navigation bar with the B10 label fix (`tab_7` = "Ajustes").
- `views/ChannelDrawer.*` — Live drawer built from the `arvore` node (`atualizarSecoes`, `preencher`, `canalEm`, runtime Favoritos); `views/PainelLateral.xml`, `views/ZapHUD.*`, `views/PinModal.*`, `views/PlayerOSD.*`, `views/HeroBanner.*` — Live/Guide/PIN/HUD/OSD/hero presentation.
- `items/CanalItem.xml`, `FonteItem.xml`, `LetraItem.xml`, `PosterItem.*`, `EpisodeItem.*`, `ProgramaItem.xml`, `AjusteItem.xml` — Adopted item/XML components (inline scripts where XML-only).
- `items/` legacy `VodCard`/`ShelfCard`/`TopTab`/`CategoryChip`/`EpisodeCard`/`SeasonChip`/`ActionPill` were retired at E1.3.
- `screens/` — 12 screens: Home, Live, Vod, Favorites, Ficha, Player, Guide, Events, Radios, Search, Settings, MinhasListas. Each owns its layout/focus key handling and calls Storage/tasks via the shell.
- `tasks/DataLoaderTask.*` — Dispatcher ops `channels|epg|destaques|events|radios` plus backbone modes (M3U, saimo index/letters/episodes, highlights, guide pipeline).
- `tasks/StreamResolverTask.*` — VOD stream resolution (letter drawers, api/stream fallback, proxy, redeflix).
- `tasks/MinhasListasTask.*` + `source/utils/LeitorM3u.brs` — user M3U list import/merge.
- `tasks/ConnectTask.*` — Saimo Connect socket server, port 8999, same-LAN trusted control.
- `tasks/AcervoTask.*` — network-only VOD catalog: `roku/indice.txt` index and 50-item pages; no UI state, `baseUrl` empty falls back to `LoadPreferences()`.
- `tasks/ArvoreCanaisTask.*` — network/CPU-only Live tree: sections from `category`, C2 channel fields, and the EPG "now" program; empty/invalid `canais` sets `error = "SemCanais"`.
- `FetchTask.*` and `EpgTask.*` were retired at E2/E6 (backup key retired / guide replaced).
