SceneGraph components that render the interface and run network work. `MainScene` owns navigation and playback, `FetchTask` handles playlist and catalog downloads, and `EpgTask` parses XMLTV.

## Summary

- `ActionPill.xml` and `ActionPill.brs` — Render each action button (play, favorite, seasons) in the series/movie detail column.
- `EpisodeCard.xml` and `EpisodeCard.brs` — Render each 396x310 episode card with a 16:9 thumbnail, episode numeral fallback, code badge, title, meta and synopsis in the series detail grid.
- `EpgTask.brs` — Task that downloads XMLTV and keeps the current and next programme for each channel.
- `EpgTask.xml` — Defines the `EpgTask` fields and script imports.
- `FetchTask.brs` — Dispatches playlist, Saimo index and shelf data, letter, episode, artwork, search, and M3U VOD downloads.
- `FetchTask.xml` — Defines the `FetchTask` fields and script imports.
- `MainScene.brs` — Controls views, navigation, settings, favorites, sync, cache, EPG, and the video player.
- `MainScene.xml` — Defines the main scene, bundled Roboto font roles, the cinematic detail view (backdrop, veils, type/frase/meta column, action pills, season chips and episode grid), poster and shelf lists, a focus-driven Discover hero, safe-area panels, empty state, guide, about, gradient player veils, spinner, semantic toasts, and timers.
- `SeasonChip.xml` and `SeasonChip.brs` — Render each season chip in the series detail season selector.
- `ShelfCard.xml` and `ShelfCard.brs` — Render a focused poster inside each Discover shelf row.
- `VodCard.xml` and `VodCard.brs` — Render each poster card in the VOD, Discover, and favorites grids.

## Constraints

- MUST keep each `.brs` file paired with an XML component of the same name.
- MUST run network downloads and large catalog parsing in Task components; `MainScene.brs` must not read `fichas.txt`.
- MUST keep every `m.top.findNode` identifier present in `MainScene.xml`; `tools/check_project.py` verifies this.

## Guidance

- SHOULD keep scene state changes in `MainScene.brs` and reusable parsing logic in `source/bslib.brs`.
- `MainScene.brs` — Discover keeps editorial shelves and updates its hero with the focused title; left enters the sidebar only at the start of a shelf row. Catalog grids use six columns, episode grids use 396x310 cards, action pills form a horizontal row (right moves between pills, only the last pill exits to the episodes), and live rows read EPG data.
- `MainScene.xml`, `ActionPill.xml`, `EpisodeCard.xml`, `SeasonChip.xml`, `ShelfCard.xml` and `VodCard.xml` — Use bundled Roboto Regular, Medium, Bold, Black and Italic faces under the Apache License 2.0 in `SaimoTV/fonts/`.
