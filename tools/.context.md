Python tooling for project validation, release packaging, artwork generation, and running the BrightScript parser tests.

## Summary

- `check_project.py` — Runs static checks on required files, versions, XML references, catalog flows, cache behavior, and documented UI invariants such as six-column catalogs and Discover shelves.
- `make_artwork.py` — Generates the PNG icon, splash, background, navigation, focus, and placeholder artwork.
- `package.py` — Builds `dist/SaimoTV-roku.zip` from `SaimoTV/` without Markdown documentation and writes its SHA-256 checksum.
- `test_parsers.py` — Runs `tools/tests/parsers_test.brs` through `npx brs` and fails on a missing pass marker.
- `tests/` — BrightScript parser tests and their fixture inputs.

## Constraints

- MUST make `tools/test_parsers.py` fail when the test output contains `TESTS_FAILED` or omits `TESTS_PASS`.
- MUST keep `tools/package.py` writing the ZIP and checksum into `dist/`.

## Guidance

- SHOULD use the npm scripts in `package.json` instead of invoking these files directly.
- SHOULD extend `check_project.py` when a new invariant needs a static guard.
