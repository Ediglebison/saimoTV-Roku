Saimo TV is a Roku SceneGraph client for live channels and an on-demand catalog. The root holds the application, build and test tooling, project documentation, and generated or ignored working directories.

## Summary

- `.agents/` — Agent framework files (personas, rules, skills); ignored by the application build.
- `.memory/` — Agent plans, reviews, session notes, and to-do files.
- `.roku-build/` — Generated BrighterScript staging output for `SaimoTV/`.
- `.tmp/` — Temporary scratch files; not application source.
- `dist/` — Generated sideload ZIPs, source archives, checksums, and validation reports.
- `docs/` — Project orientation documents, including the feature map.
- `node_modules/` — Installed npm dependencies; vendored and ignored.
- `SaimoTV/` — Roku application source, assets, and manifest.
- `tools/` — Python validation, packaging, artwork, and test-runner scripts.
- `.gitignore` — Excludes dependencies, build output, generated packages, agent configuration, and local chat transcripts.
- `.ignore` — Re-includes `.agents/` and `.memory/` for tools that honor it.
- `bsconfig.json` — BrighterScript configuration with `SaimoTV` as the build root.
- `opencode.json` — OpenCode project configuration.
- `package-lock.json` — Locked npm dependency versions for the tooling.
- `package.json` — npm scripts for artwork, checks, tests, build, and packaging.
- `README.md` — User and developer documentation for version 2.5.12.

## Constraints

- MUST keep application source under `SaimoTV/`; the BrighterScript build reads that directory.
- MUST treat `dist/` and `.roku-build/` as generated output, not source.
- MUST keep `package.json`, `package-lock.json`, and `SaimoTV/manifest` at the same version; `tools/check_project.py` verifies 2.5.12.
- MUST keep `SaimoTV/source/bslib.brs` free of UI state; the file header states this contract.

## Guidance

- SHOULD run `npm run check`, `npm test`, `npm run build`, and `npm run package` after source changes.
- SHOULD update `docs/FEATURE-MAP.md` when a user-facing flow changes.
